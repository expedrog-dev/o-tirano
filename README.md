# O Tirano

Aventura narrativa 2D inspirada em Édipo Rei, de Sófocles, desenvolvida no Construct 3.

## Jogar

https://expedrog-dev.github.io/o-tirano/

Use um computador com teclado. WASD: mover; E: interagir; Espaço: avançar diálogos; 1/2/3: responder à Esfinge; Enter: iniciar.
