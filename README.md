# O Tirano

Jogo narrativo 2D inspirado em **Édipo Rei**, de Sófocles, desenvolvido no **Construct 3**.

## De onde veio a ideia

Conheci a história de Édipo Rei em uma aula de Ética. Achei interessante transformar aquele conto grego em um jogo: explorar os cenários, conversar com personagens e acompanhar a investigação de Édipo.

## O projeto

A experiência conecta mapas, personagens, diálogos, escolhas e progressão narrativa. Inclui a estrada, Tebas, o palácio e o encontro com a Esfinge. A fonte autoral Pedro Hand participa da identidade visual.

## Abrir

1. Baixe este repositório em **Code → Download ZIP** e extraia o conteúdo.
2. No Construct 3, abra a pasta `projeto`, que contém `project.c3proj`.
3. Use a prévia do editor para testar o projeto.

A pasta reúne a estrutura editável, os mapas, personagens, folhas de eventos e recursos do jogo.

O projeto publicado é a versão disponível para teste. Ainda não há uma exportação web jogável neste repositório.

## Aprendizado

Minha maior dificuldade foi aprender por conta própria a usar o Construct 3 e pesquisar a história para compreender como adaptá-la a uma experiência interativa.
